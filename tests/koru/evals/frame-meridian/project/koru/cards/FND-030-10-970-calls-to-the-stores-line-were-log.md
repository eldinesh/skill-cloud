# FND-030 · 10,970 calls to the stores line were logged in Q3, not linked to requests

## Observation

The Q3 phone system logged 6,100 calls to the stores line at North and 4,870 at Central (10,970). The count comes from the phone system and is not linked to requests, so calls per request cannot be computed; for scale, 22,421 requests were created in UnitDesk (FND-021). Reasons for the calls are not recorded.
