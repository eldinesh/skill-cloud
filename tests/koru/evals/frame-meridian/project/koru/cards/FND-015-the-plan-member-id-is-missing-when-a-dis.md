# FND-015 · The plan member ID is missing when a discharge request arrives

## Observation

P04 reports usually receiving one of the four facts needed (member ID, what is needed, going-home date, address), and says the nurse does not know the plan member ID: the hospital system shows the hospital record number. P04 spends time matching people. In Q3, 71% of discharge needs had no member ID (FND-029, a separate source).

## Quotes

> "Member ID, what they need, when they're going home, and the address. Usually I get one of those." (P04, DAT-004)
> "The nurse doesn't know the member ID because the hospital system shows the hospital record number, not the plan ID. So I spend time matching people." (P04, DAT-004)
