# FND-035 · Engineering reports the ERP has no purchase-order API and lines over 500 USD need ERP approval

## Observation

Tom Okafor says the ERP has no API for creating purchase orders, that orders reach suppliers in a nightly EDI file, and that Finance requires every PO line over 500 USD to be approved in the ERP, which engineering cannot bypass. Tom also says an AI suggestion that a materials manager approves in one click can be built, landing in the nightly file. Engineering say-so on feasibility; it matches the written engineering note.

## Quotes

> "the ERP has no API for creating purchase orders." (Tom, DAT-009)
> "Finance has a control that every PO line over $500 gets approved in the ERP." (Tom, DAT-009)
> "We could do AI suggesting a reorder that a materials manager approves in one click. That we can build." (Tom, DAT-009)
