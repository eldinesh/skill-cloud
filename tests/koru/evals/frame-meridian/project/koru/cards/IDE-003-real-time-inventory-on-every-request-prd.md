# IDE-003 · Real-time inventory on every request (PRD R6)

## Idea

Real-time inventory levels shown on every request (PRD R6), and a live view of requests across all four hospitals (R10).

## Reverse trace

Implies that a requester cannot tell whether an item will arrive (PRB-002). The Problem is evidenced; the solution is not available: stock is known as of 02:00 plus scans on about half the units (FND-034), and a wrong status is worse than none. The client has been told (CON-005). Held as an idea; the Brief puts it out of scope as a constraint.
