# FND-038 · Five client leaders name five different results for the first release

## Observation

At the kick-off, asked what success looks like in six months, Dana (COO) names no stockouts and AI doing the ordering; Raj (VP Finance) names stockouts down without spend rising; Marcus (Director of Nursing) names nurses' time given back; Hannah (Head of Care Navigation) names nothing about a member falling between hospital and plan. Priya (Product Owner) asks Koru to help decide what the first release should be. Dana places the plan side in phase 2; Hannah says supply work is not where members get hurt. This is stakeholder say-so, not user evidence.
