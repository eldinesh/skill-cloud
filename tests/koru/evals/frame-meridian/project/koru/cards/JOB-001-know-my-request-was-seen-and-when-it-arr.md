# JOB-001 · Know my request was seen and when it arrives

Rests on INS-001 (signed, medium confidence). The Findings below are the evidence the Insight draws on.

## Job

When a unit is running low on something a patient needs and I have asked for it, I want to see that it has been seen and approved and which delivery round it is on, so I can decide whether to wait, fetch it or ask someone, without phoning.

Who: charge nurses and nurses at North and Central; the same loop for navigators (JOB-006).

## Forces

- **Push:** the status reads only "Submitted" (P01); a request showing Submitted since Tuesday (#4475); 22% never updated (FND-025); calling stores is the only check.
- **Pull:** "Just tell me where it is and when it's coming" (P01); "units can see when their stuff is on the next round" (P03).
- **Habit:** phone materials anyway; keep a stash; resubmit.
- **Anxiety:** a status that is wrong or stale, which would be worse than none (Tom's point about stock, FND-034); that nobody reads the request; that "Submitted" stays unless a manager updates it by hand.
