# Engagement AI tiers — quick reference

| | prohibited | limited *(healthcare default)* | permitted |
|---|---|---|---|
| Client material in AI tools | Never | De-identified only | Yes, per written approval |
| Transcripts / interview notes | No | After de-identification on intake | Yes (still de-identify people) |
| Screenshots of client UIs | No | Only blurred / synthetic-data rebuilds | Prefer synthetic; staging = live data |
| SkillCloud craft skills on synthetic material | Yes | Yes | Yes |
| company-handbook / internal questions | Yes | Yes | Yes |
| Credentials, contracts, patient records | Never | Never | Never |

**Unsure → limited, and ask the engagement manager today.**
**Stricter client NDA always wins.**
**Tier lives in `ux/project-context.md` with its source.**
