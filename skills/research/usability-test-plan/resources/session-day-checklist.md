# Session-day checklist — clinical usability testing

Print or keep open. The moderator runs the script; this sheet keeps the day from running you.

## Before leaving / before first session
- [ ] Reconfirmed slots with charge nurse / unit manager (yesterday) and again this morning
- [ ] Badge + escort arranged; arrival buffer for security
- [ ] Prototype loads on the actual machine you'll use; backup device charged; offline fallback (screenshots deck) ready
- [ ] Synthetic data reset to starting state for session 1; reset procedure written down
- [ ] Capture sheets printed / open per participant code (next P-numbers in the project sequence — check `ux/interviews/` for the last used)
- [ ] Consent script in hand, tier-matched sentence verified against `ux/project-context.md` (rules in `engagement-guardrails`)
- [ ] Honorarium/compliance handling confirmed (some staff can't accept cash; physician payments may be reportable)

## Every session
- [ ] Consent read verbatim; recording choice honored; notes-only fallback offered without friction
- [ ] Think-aloud calibration done (30 seconds)
- [ ] Prototype reset between participants — previous participant's trail is a confound
- [ ] Assist protocol followed: two failed approaches or a direct request, then scripted assist, logged
- [ ] Neutral acknowledgment after success and failure alike
- [ ] Interruption: pause silently, let them go, annotate; resume from task start if badge-tap reset state
- [ ] End on time even mid-task — their next obligation is clinical

## Clinical etiquette
- [ ] Out of patient sightlines; no recording where patients or live records could be captured
- [ ] If a live screen appears: look away, don't capture, note "live system observed" only
- [ ] Bare-below-elbows / hand hygiene per site policy; never touch clinical equipment
- [ ] No corridor conversations about findings — debrief off the unit

## End of day
- [ ] Same-day debrief with notetaker/observers (15 min minimum): top surprises, threshold check per task
- [ ] Notes de-identified before they enter `ux/` (P-numbers, no names, no room numbers); raw recordings stored per engagement data terms
- [ ] Anything that looked like live PHI in captures: flagged and quarantined per `engagement-guardrails`, today
- [ ] Tomorrow's slots reconfirmed
